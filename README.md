# Полное руководство по устройству и настройке PWA-расписания

## 1. Архитектура и структура файлов

Приложение представляет собой PWA (Progressive Web App) — веб-сайт, который работает как полноценное приложение на смартфоне.

/
├── index.html     — Каркас и структура приложения
├── style.css      — Оформление, стили и тёмная/светлая тема
├── script.js      — Логика, таймеры, часы и база данных расписания
├── manifest.json  — Конфигурация PWA (название, иконки, цвета)
├── icon.png       — Иконка приложения (1024x1024 px, PNG)
└── README.md      — Документация проекта

---

## 2. Как работают файлы

- index.html: Связывает все компоненты воедино. В `<head>` подгружаются внешние шрифты, стили `style.css`, иконка `icon.png` и веб-манифест `manifest.json`.
- style.css: Отвечает за адаптивную вёрстку под любые экраны (от смартфона до ПК) и поддерживает автоматическое переключение тем (светлая/тёмная) с помощью CSS-переменных.
- script.js: «Мозг» приложения. Хранит массив уроков, отслеживает текущее время, рассчитывает активный урок и оставшееся время до конца занятия (по 45-минутным интервалам). Сохраняет пользовательский выбор темы и дня в `localStorage`.
- manifest.json: Настройки PWA. Указывает браузеру, что сайт можно установить на рабочий стол без адресной строки (`display: "standalone"`), задаёт имя приложения и цвет внешней рамки (`theme_color`).

## 3. Пошаговая публикация на GitHub Pages

1. Зайдите на github.com и создайте новый публичный репозиторий (например, `schedule`).
2. Загрузите в него 6 файлов: `index.html`, `style.css`, `script.js`, `manifest.json`, `icon.png` и `README.md`.
3. Откройте **Settings** репозитория -> раздел **Pages** в левом меню.
4. В пункте **Source** выберите **Deploy from a branch**.
5. Установите ветку **main** и папку **/ (root)**, затем нажмите **Save**.
6. Через 1–2 минуты сайт станет доступен по адресу:
   `https://ИМЯ_ПОЛЬЗОВАТЕЛЯ.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`

## 4. Редактирование расписания в script.js

Чтобы изменить список уроков, откройте `script.js` и найдите объект `schedule`:

const schedule = {
  monday: [
    { time: "07:30", subject: "К-тил" },
    { time: "08:20", subject: "Технол" },
    { time: "09:10", subject: "Хим" }
  ],
  tuesday: [ ... ]
};

Правила редактирования:
- Время указывается строго в формате "ЧЧ:ММ" в кавычках (например, "07:30").
- Каждый урок оборачивается в фигурные скобки `{ ... }`.
- Между уроками внутри дня обязательно ставится запятая (после последнего урока дня запятая не нужна).

## 5. Установка ярлыка на смартфон (PWA)

1. Откройте опубликованную ссылку в Яндекс Браузере или Chrome на телефоне.
2. Нажмите меню браузера (три точки).
3. Выберите пункт **«Добавить на экран "Домой"»** (или «Установить приложение»).
4. На рабочем столе появится иконка, запускающая сайт в режиме отдельного приложения.

---

## 6. Решение проблем с отображением иконки

Если вместо вашей иконки отображается глобус или стандартный значок:
1. Регистр файлов: Убедитесь, что файл в репозитории называется строго `icon.png` (все буквы строчные).
2. Сброс кэша: Если браузер запомнил старое изображение, измените строки подключения в `index.html`, добавив версию:
   `<link rel="icon" type="image/png" href="./icon.png?v=2">`
3. После изменения обновите страницу в режиме Инкогнито или пересоздайте ярлык на рабочем столе.
