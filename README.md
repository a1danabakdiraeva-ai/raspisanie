# Моё расписание

Простой статический сайт с расписанием уроков на 5 учебных дней. Работает полностью в браузере — без сервера, без базы данных, без backend. Можно разместить на GitHub Pages бесплатно.

## Что внутри

```
/
├── index.html   — страница сайта
├── style.css    — оформление (светлая и тёмная тема)
├── script.js    — вся логика, включая расписание
└── README.md    — эта инструкция
```

## Как опубликовать на GitHub Pages

1. Зайдите на [github.com](https://github.com) и создайте новый репозиторий (New repository). Можно назвать его, например, `schedule`.
2. Загрузите в него 4 файла: `index.html`, `style.css`, `script.js`, `README.md`.
   - Это можно сделать через кнопку **Add file → Upload files** на странице репозитория.
3. Откройте вкладку **Settings** репозитория.
4. В боковом меню найдите раздел **Pages**.
5. В пункте **Source** выберите **Deploy from a branch**.
6. Выберите ветку **main** и папку **/ (root)**.
7. Нажмите **Save**.
8. Подождите 1–2 минуты — GitHub покажет ссылку вида:

   ```
   https://ИМЯ_ПОЛЬЗОВАТЕЛЯ.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/
   ```

9. Откройте эту ссылку — сайт готов.

Все пути к файлам в проекте относительные (`./style.css`, `./script.js`), поэтому сайт корректно откроется по такому адресу с подпапкой — ничего дополнительно настраивать не нужно.

## Как изменить расписание

Откройте файл **`script.js`**. В самом начале файла найдите комментарий:

```javascript
// ===== ИЗМЕНЯЙ РАСПИСАНИЕ ЗДЕСЬ =====
const schedule = {
  monday: [
    { time: "07:30", subject: "К-тил" },
    ...
  ],
  ...
};
```

Это единственное место, которое нужно редактировать. Всё остальное в файлах трогать не обязательно.

### Как устроен один урок

```javascript
{ time: "07:30", subject: "К-тил" }
```

| Поле      | Обязательно | Что это |
|-----------|-------------|---------|
| `time`    | да          | Время начала урока, строго в формате `"ЧЧ:ММ"` |
| `subject` | да          | Название предмета |

Кабинет и учитель сейчас не используются — на карточке урока показывается только время и предмет. Если позже захочешь их вернуть, можно дописать в любой урок `room: "101"` и/или `teacher: "Иванов"` — сайт покажет их отдельной строкой под названием предмета. Это необязательные поля.

### Как добавить второй, третий и следующий урок

Уроки одного дня — это список в квадратных скобках `[ ... ]`, где элементы разделены запятой. Чтобы добавить урок, скопируйте одну строку и вставьте её ниже, поставив запятую после предыдущей строки:

```javascript
monday: [
  { time: "07:30", subject: "К-тил" },
  { time: "08:20", subject: "Технол" },
  { time: "09:10", subject: "Хим" }
  // ← сюда можно добавить ещё один урок точно так же, через запятую выше
],
```

### Время звонков

Уроки длятся 45 минут, перемены между ними — 5 минут, а после 3-го урока — большая перемена 10 минут. Отсюда и получаются времена начала уроков:

| Урок | Начало |
|------|--------|
| 1    | 07:30  |
| 2    | 08:20  |
| 3    | 09:10  |
| — большая перемена (10 мин) — | |
| 4    | 10:05  |
| 5    | 10:55  |
| 6    | 11:45  |

Если поменяется время начала первого урока или длительность уроков/перемен — пересчитай эту таблицу и впиши новые значения `time` у всех уроков в `script.js`. Длительность урока для определения статуса «сейчас/завершён» также задана отдельно, в константе `LESSON_LENGTH_MIN` (сейчас `45`) в начале `script.js` — поменяй её, если изменится длительность урока.

Порядок уроков в списке — это порядок, в котором они покажутся на сайте (по времени). Номер урока (01, 02, 03…) сайт проставляет автоматически, вручную его указывать не нужно.

### Как отредактировать день

Каждый день недели — это отдельный список: `monday`, `tuesday`, `wednesday`, `thursday`, `friday`. Меняйте нужный список так же, как показано выше. Один день никак не влияет на другой.

### Частые ошибки при редактировании

- Не забывайте запятую **между** уроками (но не после последнего урока в списке).
- Время указывайте всегда в кавычках и в формате `"08:00"` (а не `8:00` или `08.00`).
- Каждая открывающая фигурная скобка `{` должна иметь закрывающую `}`.

Если после изменений сайт перестал открывать расписание (пустая страница или ошибка в консоли браузера) — скорее всего, где-то пропущена запятая или кавычка. Проверьте последнее изменённое место.

## Возможности сайта

- Переключение между 5 днями недели без перезагрузки страницы.
- Автоматическое определение сегодняшнего дня при открытии сайта (в выходные — сообщение «Сегодня выходной», с возможностью вручную открыть любой день).
- Запоминание последнего выбранного вручную дня (через `localStorage`).
- Автоматическое определение текущего и следующего урока по времени, с живым обновлением.
- Часы с текущим временем.
- Светлая и тёмная тема с сохранением выбора (через `localStorage`).
- Адаптивная вёрстка: от телефонов на 320 px до больших экранов.

## Ограничения

- Расписание меняется только через редактирование `script.js` — админ-панели или формы редактирования в браузере нет, как и не должно быть в полностью статическом проекте.
- Все данные хранятся локально в браузере каждого посетителя (тема оформления и последний выбранный день) — они не синхронизируются между устройствами.
